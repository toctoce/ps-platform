# frontend

React + Vite 기반 프론트엔드 애플리케이션입니다.

## 최초 설치

```bash
cd frontend
npm install
```

## 실행 방법

```bash
cd frontend
npm run dev
```

기본 실행 주소:

```text
http://localhost:5173
```

Vite 개발 서버는 `/api` 요청을 백엔드로 프록시합니다.
프론트에서 API를 사용하려면 백엔드가 `http://localhost:8080`에서 실행 중이어야 합니다.

## 빌드

```bash
cd frontend
npm run build
```
