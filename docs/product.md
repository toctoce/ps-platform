# 제품 메모

## 프로젝트 이름

PS Platform

## 현재 서비스 이름

Bbangorithm

## 목표

PS Platform은 알고리즘 문제 풀이와 온라인 채점을 제공하는 플랫폼입니다.

## MVP

사용자는 알고리즘 문제를 풀고 코드를 제출할 수 있습니다.

시스템은 제출된 코드를 채점하고 결과를 보여줍니다.

## 핵심 MVP 기능

* 문제 등록
* 문제 카테고리 관리
* 테스트 케이스 등록
* 문제 목록
* 문제 상세
* 카테고리별 문제 풀이
* 랜덤 5개 문제 풀이
* 코드 제출
* 채점 결과

## 문제 정보

문제는 최소한 다음 정보를 가집니다.

* 제목
* 설명
* 입력 설명
* 출력 설명
* 시간 제한(ms)
* 메모리 제한(MB)
* 카테고리

카테고리는 문제를 주제별로 묶기 위한 값입니다.

예시:

* 구현
* 완전탐색
* 정렬
* 이분 탐색
* 그래프
* DFS/BFS
* 다이나믹 프로그래밍
* 그리디

## 풀이 모드

사용자는 다음 방식으로 문제를 풀 수 있어야 합니다.

* 카테고리별 문제 풀기
* 랜덤 5개 문제 풀기

카테고리별 문제 풀기는 사용자가 선택한 카테고리에 속한 문제만 보여줍니다.

랜덤 5개 문제 풀기는 전체 문제 중 5개를 무작위로 선택해서 보여줍니다.

문제가 5개보다 적으면 가능한 개수만 보여줍니다.

## 첫 지원 언어

Python, C++, Java를 지원합니다.

다른 언어는 나중에 추가할 수 있습니다.
